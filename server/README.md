# MVP 服务器 — 登录与权限测试

这是需求文档 M1 阶段的最小可行版本，**只测试服务器端的多用户登录与角色权限体系**（超级管理员 vs 普通用户），不包含题库、组卷、AI 批改等功能，那些会在后续里程碑中在此基础上继续搭建。

## 技术栈

- Node.js（v22+ 内置 `node:sqlite`，无需安装数据库或原生编译依赖）
- Express（HTTP 服务）
- bcryptjs（密码加盐哈希）+ jsonwebtoken（登录态）

这套技术选型是为了在本地快速验证权限逻辑；正式部署时会迁移到 Cloudflare Workers + D1（同为 SQLite 方言，迁移成本低），见 `docs/requirements.md` 第 6.3 节。

## 已实现的能力

- `POST /api/auth/login` — 用户名+密码登录，返回 JWT。
- `GET /api/me` — 需要登录，返回当前用户信息（用于验证 token 有效性）。
- `POST /api/admin/users` — **仅超级管理员**，创建普通用户账号，返回一次性初始密码。
- `GET /api/admin/users` — **仅超级管理员**，查看所有用户列表。
- `POST /api/admin/users/:id/reset-password` — **仅超级管理员**，重置指定用户密码。
- `PATCH /api/admin/users/:id/status` — **仅超级管理员**，启用/禁用指定用户（超级管理员账号本身不可被禁用）。
- 权限隔离：普通用户访问任何 `/api/admin/*` 接口一律返回 403；未登录访问任何受保护接口返回 401；账号被禁用后无法登录。

## 本地运行

```bash
cd server
npm install
cp .env.example .env      # 按需修改 JWT_SECRET / 超级管理员用户名密码
npm run seed               # 创建唯一的超级管理员账号（密码只显示这一次）
npm start                  # 启动服务，默认 http://localhost:8787
```

## 运行自动化测试

`test/smoke.sh` 会启动一个使用临时数据库的独立服务实例，完整走一遍登录、建号、越权拦截、改密、禁用等流程并断言结果，跑完自动清理，不影响你本地的 `.env`/数据库：

```bash
cd server
npm test
```

当前测试覆盖的场景（18 项断言均通过）：超级管理员登录、错误密码拒绝、创建普通用户、普通用户登录、普通用户访问后台接口被拒绝(403)、未登录访问被拒绝(401)、后台查看用户列表、重置密码后旧密码失效新密码生效、禁用账号后无法登录、超级管理员账号不可被禁用。
