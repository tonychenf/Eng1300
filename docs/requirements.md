## 1. 样卷结构分析（本次已解析的真题）

将样卷渲染为图片逐页解析后，得到如下结构（**该 PDF 没有文字层，是纯图片扫描件**，见第 6.1 节的技术影响）：

| 部分 | 题型 | 题号范围 | 题量 | 每题分值 | 小计 | 形式 |
|---|---|---|---|---|---|---|
| 第一部分 | 阅读判断 (True/False/Not Given) | 1–10 | 10 | 1分 | 10分 | 1篇短文 + 10个判断句，单选A/B/C |
| 第二部分 | 阅读理解选择 | 11–15 | 5 | 2分 | 10分 | 1篇短文 + 5题四选一 |
| 第三部分 | 段落大意归纳 + 句子补全 | 16–25 | 10 | 1分 | 10分 | 1篇短文(5段)，Task1: 5段配6个标题选1；Task2: 5句配6个选项选1 |
| 第四部分 | 填句补文 | 26–30 | 5 | 2分 | 10分 | 1篇短文5空 + 6个句子选5个还原 |
| 第五部分 | 填词补文（词库选词） | 31–40 | 10 | 1.5分 | 15分 | 1篇短文10空 + 12个词选10个（原词形式，不需变形） |
| 第六部分 | 完形填空（词形变换） | 41–50 | 10 | 1.5分 | 15分 | 1篇短文10空，给出词根，需写出正确形式（主观填空，非选择） |
| 第七部分 | 短文写作 | 51 | 1 | 30分 | 30分 | 根据中文写作要点写100词左右英文短文 |
| **合计** | | | **51题** | | **100分** | 选择题部分(1-40) + 非选择题部分(41-51) |

**关键观察：**
- 这是全国自考统一命题科目的**高度标准化**试卷：题型、题量、分值、每部分对应的分值权重逐年基本固定（这是"根据历史真题的题数难度来出题"这一需求得以自动化实现的前提）。
- 第1–40题为客观题（可自动判分），第41–51题为主观题（第41–50空需要判断词形变化正误，第51题作文需要人工/AI评分）。
- 试卷本身**未标注考试时长**（时长信息通常在准考证/考场规则中），需要你确认或以自考英语(二)官方公布的考试时长为准（**这是待确认问题，见第9节**）。

## 2. 系统总体目标

1. **题库化**：把你上传的历年真题（多份 PDF）结构化存入题库，包含原文、题目、选项、正确答案、（可选）官方解析。
2. **智能组卷**：点一下"随机出题"，系统按照历史真题的**题型结构、题量、分值权重**自动组一套新的模拟卷（题目从题库中抽取，避免抽到你已经完全掌握或最近刚做过的题，支持难度倾向调节）。
3. **限时作答**：给出模拟卷后进入答题界面，有倒计时，时间到自动交卷，支持中途保存/暂停。
4. **自动批改 + AI 讲评**：客观题自动判分；主观题（完形词形、作文）调用你提供的 AI 接口批改并打分。
5. **错题分析**：针对每道错题，AI 生成"错误原因分析 + 该考点的记忆要点/知识卡片"，并沉淀到"错题本"供复习。
6. **能力评估与预测**：结合你的历史做题记录（各题型正确率、错题分布、进步趋势）与全部真题的整体难度分布，评估"如果现在去做一套同类型新卷，预计能得多少分"，输出预测分数区间 + 分项能力雷达图 + AI 定性点评。
7. **AI 接口自定义**：系统内提供"设置"页面，可以自行填写你自己的 AI API（Base URL / API Key / 模型名等），系统所有 AI 相关功能都通过这个统一入口调用。

## 3. 功能模块详细需求

### 3.1 题库管理模块

- **导入真题**：上传 PDF（支持多份批量上传），系统自动识别是否有文字层：
  - 有文字层 → 直接文本抽取；
  - 无文字层（如本次样卷）→ 将每页渲染成图片，调用你配置的 AI（需具备图片理解/视觉能力）进行版面解析，输出结构化 JSON（部分、题号、原文、题干、选项、正确答案）。
- **人工校对界面**：AI 解析结果**必须**经过一步"校对确认"页面——逐题展示"AI 识别结果 vs 原图片"，允许你手动修改文字、选项、答案后再入库，避免识别错误污染题库和后续判分。
- **题库结构管理**：按"科目→年份/月份→部分(Section)→题目(Question)"层级组织；每道题记录所属部分类型、原文段落归属、分值、正确答案、（可选）官方解析文本。
- **答案库**：官方标准答案与评分参考一并存入，供自动判分和 AI 批改时作为参照标准（比如第9节样卷中的评分参考文字"英、美拼写均可接受；大小写错误不扣分"这类判分规则也建议结构化保存，供自动判分逻辑与 AI 批改共同遵守）。
- **题库统计**：查看当前已入库的真题套数、各题型题目数量、覆盖的年份范围。

### 3.2 智能组卷模块（随机出题）

- **组卷模板**：以已入库真题的"部分数量、每部分题量、每题分值、题型顺序"为模板（如题量/分值出现多个版本，取**最新一次**真题结构为默认模板，或允许你手动选择以哪一年结构为准）。
- **抽题策略**：
  - 按模板每个部分单独从题库对应分类中抽题，保证部分结构与真实考试一致；
  - 支持"难度"参数（简单/正常/困难/随机），依据你历史该题所在部分/考点的正确率对候选题目做加权抽样；
  - 避免短期内重复抽到同一题（记录"最近N次出现过的题目"进行规避，除非题库题量不足）；
  - 阅读类题目以"篇章"为最小抽取单位（一篇短文+其所有子题一起抽取，不能只抽单题打散原文语境）。
- **组卷预览**：生成后展示本套卷的题型构成、总分、预计时长，确认后进入作答。

### 3.3 限时作答模块

- **倒计时**：页面顶部常驻倒计时，时长 = 模板对应的官方考试时长（第9节需你确认具体分钟数，或按题型分别设置）。
- **交互方式**：按题型还原真实作答体验——单选题点选选项、填词补文可拖拽/点选词库、完形填空为文本输入框、作文为多行文本框（含字数统计）。
- **自动交卷**：时间耗尽自动提交并锁定，禁止继续修改；提前完成可手动交卷。
- **断点保存**（可选但建议）：意外关闭页面后可恢复未完成的作答进度（同一次考试内）。

### 3.4 自动判分与 AI 批改模块

- **客观题自动判分**（第1–40题：判断题/选择题/搭配题/词库填词）：系统直接比对标准答案，逐题给分，无需 AI。
- **主观题 AI 批改**：
  - 第41–50题（词形变换填空）：调用 AI 判断你所填单词是否为正确词形，给出对/错及正确答案（此题型语法规则明确，AI 可高置信度判定，必要时叠加规则校验，如拼写与词性检查）。
  - 第51题（作文）：调用 AI 依据"内容要点覆盖度、语言准确性、词汇丰富度、篇章连贯性、字数要求"等维度评分（参照真实自考作文评分标准的分档描述），输出分数 + 分维度点评 + 修改建议 + 一份可对照的范文思路。
- **成绩单**：交卷后立即生成本次成绩单：各部分得分/满分、总分、正确率、比历史平均的高低。

### 3.5 错题分析与学习要点模块

- 对每道判错（或 AI 判定不完全正确）的题目，自动调用 AI 生成：
  1. **错误原因分析**（是词汇量不足/语法点误解/阅读理解偏差/审题失误等，需引用原文/选项定位说明"为什么错、正确逻辑是什么"）；
  2. **该考点的记忆要点**（提炼成可复用的知识卡片，如某个词组搭配、某个语法规则、某类阅读题的做题技巧）。
- **错题本**：所有错题及分析长期保存，支持按"考点类型/错误原因/时间"筛选查看，支持"重新只做错题本里的题"这一二次练习模式。
- **知识卡片库**：AI 提炼出的记忆要点去重后汇总成个人专属的"知识点卡片集"，可作为考前速记材料浏览或导出。

### 3.6 能力评估与预测模块

评估"如果现在再做一套同类型新卷，预计能得多少分"，采用**统计模型 + AI 定性评估相结合**的方式：

- **统计层**：基于你历史所有考试记录，按题型/部分分别计算最近一段时间的正确率与得分趋势（如加权最近N次表现，越近权重越高），结合官方真题各部分分值权重，加权推算出一个"预测总分"及各部分预测得分。
- **AI 定性层**：把你的历史错题分布、薄弱考点、进步趋势喂给 AI，由 AI 给出：预测分数区间、当前水平定位（如"预计XX-XX分，接近及格线/良好水平"）、最值得优先补强的2-3个薄弱点、针对性备考建议。
- **展示**：能力雷达图（按各部分/技能维度）、历史分数趋势折线图、预测分数卡片（含统计模型分数与AI综合意见）。

### 3.7 AI 接口设置模块

- **设置页面**：可配置 API Base URL、API Key、模型名称、（如需要）请求协议类型（默认按 OpenAI Chat Completions 兼容格式对接，多数第三方/国产模型中转服务均兼容此格式；如你提供的 API 协议不同，需要另行告知具体接口规范以便适配，见第9节待确认问题）。
- **连通性测试**：设置页提供"测试连接"按钮，验证 Key 是否有效、能否正常返回结果。
- **安全性**：API Key 仅保存在你本机浏览器本地存储中，不上传到任何第三方服务器；所有 AI 调用均由浏览器直接发起请求到你指定的 API 地址。
- **用量与成本提示**（可选）：显示每次调用大致消耗的 token 数，便于你控制成本。

### 3.8 历史记录与统计看板

- 所有历次模拟考试记录（时间、总分、各部分得分、用时）列表可查看、可导出。
- 统计看板：正确率随时间变化曲线、各题型薄弱环节分布、做题总量统计。
- **数据备份**：支持一键导出全部题库+做题记录为 JSON 文件，以及导入恢复（防止清浏览器缓存导致数据丢失）。


## 6. 非功能需求与技术方案建议

### 6.1 PDF 解析的技术约束（重要）

经检测，本次样卷 PDF **不含文字层**（`pdftotext` 提取结果为空），是排版后转图片/扫描类型的 PDF。这意味着：
- 常规文本提取（复制粘贴级别）对这批真题**完全无效**；
- 必须走"页面转图片 + AI 视觉模型解析"的路线，这也是本方案把 PDF 导入功能绑定"你提供的 AI API 需具备图片理解能力"的原因；
- 若你之后要导入的其它真题 PDF 是可选中文字的普通 PDF，系统会自动识别并直接走文本抽取（更快更准，无需消耗 AI 调用）。

### 6.2 技术栈建议

- **形态**：纯前端单页应用（SPA），无需服务器后端，可作为静态网站部署（本地打开或部署到 GitHub Pages / 任意静态托管）。
- **技术选型**：React + TypeScript + Vite；UI 用 Tailwind CSS；图表用于统计看板（如 Recharts）；PDF 转图片在浏览器端用 pdf.js 完成。
- **数据存储**：浏览器 IndexedDB（题库、做题记录、错题本、设置均本地持久化），配合"导出/导入 JSON"做备份，避免清缓存丢数据。
- **AI 调用**：浏览器直接向你配置的 API 地址发起请求（默认 OpenAI 兼容协议），无中间服务器，你的 Key 不经过任何第三方。

### 6.3 其它非功能需求

- 单用户场景，无需登录注册体系。
- 移动端/桌面端浏览器均可用（响应式布局），优先保证桌面端体验（做题录入场景更常见）。
- AI 调用失败（网络错误/Key 无效/超额度）需有清晰的报错提示，且不能导致客观题判分和数据保存受影响（AI 只增强主观题和分析功能，核心记分流程不依赖 AI 也能跑通）。

## 7. 待你确认的问题（Open Questions）

1. **考试时长**：样卷本身未标注时长，请提供官方时长（自考英语(二)标准考试时长），或告知是否按你自己设定的时长练习即可。
2. **AI API 协议**：你将提供的 AI API 是否为 OpenAI Chat Completions 兼容格式（如 `POST /v1/chat/completions`）？是否具备**图片/视觉理解能力**（用于解析扫描版 PDF 真题）？如果不是标准协议，请提供接口文档或示例请求。
3. **题库来源范围**：目前只有这1份真题（2024年4月）。是否后续会持续上传更多年份真题？初始阶段题库较小时，"随机组卷"可能会重复抽到同一批题目，是否可接受，还是需要我此阶段先手动补充/生成一些同结构的练习题以扩充题库？
4. **部署方式**：是本地打开使用（如打开 index.html 或本地 `npm run dev`），还是需要我帮你部署到某个可通过链接访问的静态网站（如 GitHub Pages）？
5. **数据存储位置**：确认纯本地浏览器存储（IndexedDB）是否满足你的需求，还是希望能跨设备同步做题记录（那将需要引入云端存储方案，复杂度会显著提升）？

## 8. 建议的开发里程碑

1. **M1 - 题库基础**：PDF 导入解析（AI 视觉识别 + 人工校对）、题库存储与浏览。
2. **M2 - 组卷与作答**：智能组卷逻辑、限时作答界面、客观题自动判分、成绩报告。
3. **M3 - AI 增强**：作文/完形 AI 批改、错题分析与知识卡片、AI 接口设置页。
4. **M4 - 评估与统计**：能力评估模型（统计+AI）、历史统计看板、数据导入导出。
