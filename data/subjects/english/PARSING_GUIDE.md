# 真题解析规范（供解析任务参考，非最终产品文档）

这份文件定义了把一份自考英语真题 PDF 解析成结构化 JSON 题库文件的规则。目标是让每一份真题的解析结果，字段、命名、考点标签风格保持一致，方便后续统一发布。

## 1. 输出文件与顶层结构

每份真题输出为**一个 JSON 文件**，路径由任务指定（形如 `data/exams/00015-2015-04.json` 或 `data/exams/13000-2024-10.json`）。顶层结构：

```json
{
  "examId": "00015-2015-04",
  "title": "2015年4月高等教育自学考试英语(二)试题",
  "year": 2015,
  "month": 4,
  "courseCode": "00015",
  "courseName": "英语(二)",
  "sourceFile": "e8194fb2-2015_04____________.pdf",
  "totalScore": 100,
  "timeLimitMinutes": 150,
  "status": "待校对",
  "sections": [ /* 见第2节 */ ],
  "parsingNotes": [ /* 见第4节，字符串数组，记录解析中遇到的不确定/需要人工复核的地方 */ ]
}
```

- `examId` 格式：`<courseCode>-<year>-<month两位数>`，如 `00015-2015-04`、`13000-2024-10`。
- `year`/`month` 必须以**试卷标题页实际印刷的年月**为准，不要用文件名猜测（文件名有时和实际内容不符）。
- `courseCode`/`courseName` 同样以标题页印刷的课程代码/名称为准。目前已知两种：`00015`《英语(二)》、`13000`《英语(专升本)》。
- `status` 固定填 `"待校对"`（尚未经人工校对，不能直接进组卷）。

## 2. Section（部分）结构

按试卷实际印刷的"第 X 部分"顺序列出。00015《英语(二)》历年结构通常是这7个部分（但请以每份试卷实际印刷内容为准，不要生搬硬套，如果某年结构不同，按实际记录并在 `parsingNotes` 里说明差异）：

| type 取值 | 说明 | 典型分值 |
|---|---|---|
| `阅读判断` | 短文 + 10题 True/False/Not Given | 10分 |
| `阅读理解选择` | 短文 + 5题四选一 | 10分 |
| `段落大意与句子补全` | 短文(分段) + 标题匹配 + 句子补全两个任务 | 10分 |
| `填句补文` | 短文5空 + 6选5句子 | 10分 |
| `填词补文` | 短文10空 + 词库选词 | 15分 |
| `完形填空` | 短文10空 + 词形变换(给词根，写正确形式) | 15分 |
| `写作` | 根据中文要点写英文短文 | 30分 |

13000《英语(专升本)》若结构与上表一致，直接复用；若不同，按实际印刷内容记录 type（可以自拟简短准确的 type 名称），并在 `parsingNotes` 说明"该课程结构与00015不同，具体为……"。

每个 section 的结构：

```json
{
  "sectionId": "00015-2015-04-s1",
  "type": "阅读判断",
  "order": 1,
  "passageTitle": "Using Music to Change Your Mood",
  "passageText": "完整短文原文，段落之间用\\n\\n分隔",
  "scorePerQuestion": 1,
  "totalScore": 10,
  "questions": [ /* 见第3节 */ ]
}
```

- `sectionId` 格式：`<examId>-s<序号>`。
- `passageText` 必须是**完整、逐字**的原文（英文短文），不要摘要或省略；这是后续学生做题时要展示的内容。段落大意/填句补文/填词补文/完形填空这些"短文中有空格"的题型，`passageText` 里空格处保留题号占位，如 `___(26)___`，具体空格怎么呈现给用户由前端决定，这里只需要完整还原原文+空格位置。
- 写作部分没有 passageText（或者填写中文写作要求原文），有 `writingPrompt` 字段填写完整的中文写作要求。

## 3. Question（题目）结构

```json
{
  "questionId": "00015-2015-04-q1",
  "order": 1,
  "questionType": "single_choice",
  "stem": "题干文本（判断题/选择题的题干，或词形变换题给出的词根提示）",
  "options": ["A. True", "B. False", "C. Not Given"],
  "answer": "B",
  "answerExplanation": "简短说明为什么是这个答案，引用原文定位依据；如果官方答案页有评分说明（如英美拼写均可接受），也记录在这里",
  "knowledgePoints": ["阅读细节定位"],
  "difficultyTag": null
}
```

字段说明：
- `questionId` 格式：`<examId>-q<全卷题号>`（题号用试卷上印刷的题号，如第26题就是 `...-q26`）。
- `questionType` 取值：`single_choice`（单选，含判断题ABC/四选一/标题匹配/句子补全/填句补文/填词补文选择）、`fill_blank_transform`（完形填空词形变换，主观填空题）、`essay`（写作）。
- `options`：只有 `single_choice` 需要，按试卷印刷顺序列出全部选项原文（含字母前缀）。搭配类题目（如段落配标题、句子配选项）options 是**该题所在任务的完整候选池**（例如第16-20题共享第20节列出的6个标题选项A-F）。
- `answer`：客观题填正确选项字母（如 `"B"`）；完形填空词形变换题填正确单词（如 `"lost"`）；写作题此字段留空字符串 `""`。
- `answerExplanation`：尽量简洁准确，不要编造，如果官方只给了答案没给解析，就写"官方仅给出答案，无详细解析"，不要杜撰一个听起来合理但你不确定的解析。
- `knowledgePoints`：见第5节标签体系，1个题可以打1-2个标签，不要打超过3个。

## 4. 关于准确性：不确定的地方必须如实记录

这是要进真实题库、用于自动判分的数据，**准确性优先于完整性**。如果遇到：
- 图片模糊、字迹不清、无法确定某个字母/单词；
- 官方答案页缺失某几题的答案；
- 版式混乱导致题目和选项对应关系不确定；

**不要猜一个看似合理的答案**，而是：该字段填你能确定的最佳猜测，并在顶层 `parsingNotes` 数组里用一条字符串说明"第X题的XX不确定，原因是……，需要人工核对原图"。`parsingNotes` 里的每一条都会在后续人工校对环节被逐条检查。

## 5. 考点标签体系（尽量复用，不要随意发明新词）

按 section 类型给出的候选标签库，**优先从下表里选**；确实不合适再新增，新增时保持"四字左右、语义精确"的风格（参考下表的措辞方式），不要用整句话当标签。

- **阅读判断 / 阅读理解选择**：阅读细节定位、阅读推理判断、观点态度理解、段落主旨理解、词义猜测
- **段落大意与句子补全**：段落大意概括、连贯性衔接、逻辑关系判断
- **填句补文**：连贯性衔接、逻辑关系判断
- **填词补文**：词汇辨析、固定搭配
- **完形填空（词形变换）**：动词时态、名词单复数、词性转换、比较级最高级、被动语态、副词构词、形容词构词
- **写作**：写作-说明类、写作-观点类、写作-记叙类（根据具体写作任务判断属于哪一类，不确定就写"写作-综合"）

## 6. 处理流程建议

1. 先用 `pdftotext -layout <文件> -` 试一下有没有文字层；本批次文件目测都是图片扫描件（和最早分析的样卷一样），大概率需要 `pdftoppm -png -r 150 <文件> <前缀>` 转图片后用 Read 工具逐页阅读。
2. 先读完整份试卷摸清结构（部分数量、每部分题量），再读答案页（通常在最后1-2页，标题类似"XXXX年X月...英语(二)试题答案及评分参考"），把答案和题目一一对应上。
3. 全部读完、确认无误后，一次性写出完整 JSON 文件到指定路径。
4. 写完后用 `python3 -c "import json; json.load(open('<路径>'))"` 校验一下 JSON 格式没写错。
